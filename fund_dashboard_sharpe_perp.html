Rolling Sharpe Ratio

Measures risk-adjusted returns over a rolling time window using the formula:

Sharpe Ratio = (Mean Return - Risk-Free Rate) / Standard Deviation of Returns

Interpretation:

  • Values > 1: Good risk-adjusted performance
  • Values > 2: Very good performance
  • Values > 3: Excellent performance
  • Negative values: Returns below risk-free rate

Risk-free rate is set to 0% when unavailable. Rolling window starts from the first possible calculation date.
